# PST Folder

Place `.pst` or `.ost` files in case/search folders under this directory, for example:

```text
PST/
  Case 1/
    Search 1/
      mailbox.pst
```

The browser shows those folders as selectable scopes in the left pane. If you place
mailboxes directly in `PST/`, they appear under the `PST root` scope as a fallback.
